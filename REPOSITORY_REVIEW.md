# Ревью проекта — 7 сентября 2026

## Текущая архитектура

Проект исследует перенос семантической структуры замороженного OpenCLIP/SpLiCE
в визуальный энкодер при ложных корреляциях объекта и контекста.

```text
Training images → frozen OpenCLIP + SpLiCE → aligned feature cache
  → concept groups → full-subspace projection + null audit → sparse CRP graph
  → graph-aware sampler + SimCLR + confidence-weighted backbone KL
  → frozen backbone → supervised linear probe
```

Граф и SSL не используют целевые или групповые метки. Для линейной оценки
используются метки и сбалансированная обучающая подвыборка. CRPv4 добавляет
опциональные пространственные свидетельства. Текущий отдельный эксперимент
`frozen_concept_distill` сравнивает перенос CLIP, реконструкции SpLiCE,
перемешанной реконструкции и согласованный baseline. Завершённых результатов
этого эксперимента в проверенных локальных артефактах нет.

- `splice/ssl_regularization.py` и `splice/crp_diverse.py`;
- `tests/test_crp_diverse.py`;
- оба старых `splice_cbm.py`;
- `discover_splice_spurious_concepts.py`, `summarize_splice_scores.py`,
  `summarize_discovery_comparison.py` и `render_report_figure.py`;
- старый `teacher_graph.concepts.json`.

Из CLI, загрузчиков данных и обучения удалены зависимые старые режимы
аугментации, корреляционной регуляризации и синтеза. Сохранены обычный SimCLR,
CRP и новый прямой перенос. Метаданные выбранных групп теперь соответствуют
текущему графу. README, карта проекта и статья обновлены.

| Несколько поколений SSL в одном интерфейсе | Старые ветви CLI и датасетов усложняли запуск | Удалены старые режимы и их зависимости |

и неиспользуемая внешняя библиография. Статья содержит собственные ссылки.

Актуальные результаты и модели не удалялись. `tmp/crp_signal_checks_v1` сохранён: несмотря
на название каталога, это источник актуальных научных результатов. CoBalT и
пространственные инструменты сохранены как доступные абляции. Локальные
пользовательские настройки не изменялись.
